# Perimeter Defense

Новая реализация Tower Defense + Match-3.

## Основная механика
- Враги непрерывно движутся по маршруту к базе.
- Башни автоматически выбирают цели и атакуют по собственному таймеру.
- Поле Match-3 работает параллельно бою: комбинации из трёх и более кристаллов дают ресурсы.
- Ресурсы тратятся на покупку пулемётных и ракетных башен.
- Пропущенные враги уменьшают здоровье базы; волны постепенно усложняются.

## Сборка
Android APK собирается через GitHub Actions. Локальная сборка не требуется.
